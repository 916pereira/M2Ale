# Thindesk

Sistema de gerenciamento de chamados técnicos com dashboard administrativo para uma lanchonete/pizzaria.

## Objetivo

Permitir o acompanhamento de chamados técnicos relacionados à operação de pedidos, disponibilizando indicadores, gráficos, rankings e filtros.

## Tecnologias

- React
- Node.js
- Express
- MySQL
- Git e GitHub

## Estrutura do projeto

- backend: API REST e regras de negócio
- frontend: Dashboard administrativo
- database: Scripts SQL
- docs: Documentação e evidências dos testes

## Requisitos funcionais

- RF01: Indicadores gerais de chamados técnicos
- RF02: Análise de chamados atendidos por período
- RF03: Situação dos chamados
- RF04: Tipos de chamados mais atendidos
- RF05: Filtros de consulta
- RF06: Integração com a API
- RF07: Atualização e tratamento dos dados
